# My New Project

# \## Y nghia cac lenh Git

# 

# \- git init: Khoi tao kho Git tren may tinh.

# \- git branch -M main: Doi ten nhanh hien tai thanh main.

# \- git add README.md: Dua thay doi cua README.md vao vung chuan bi commit.

# \- git commit -m "Add README.md file": Luu thay doi kem thong diep.

# \- git remote add origin URL: Ket noi kho tren may voi kho GitHub.

# \- git push -u origin main: Day commit len GitHub va thiet lap nhanh theo doi.
